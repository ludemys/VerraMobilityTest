# Word List

## Summary

This is a project that, given a file with a list of words, outputs all the 6-letter words which can be built using another two words on the list.

## Execution

To execute, run the command 'app:find-words' with the symfony console on the project root.
```bash
bin/console app:find-words
```

## Testing

To run tests, run the command 'vendor/bin/phpunit' with the symfony console on the project root.
```bash
vendor/bin/phpunit
```
